01要解决的问题和使用场景

问题

学生在平板上演算时，常常想看一眼函数图像、验算一个积分或极限、把随手画的图变成标准的几何图形。现在的做法是切到计算器或作图软件，把式子重新敲一遍——手写和工具之间来回切换，思路被打断。

我们的做法

不让学生离开草稿纸：AI 直接读懂手写，结果原地出现在纸上。AI 负责「读懂」（手写 → LaTeX），计算交给本机的符号和数值方法，不让大模型去算。面向中学和大学低年级学生。

一次完整的操作

① 写整屏一张纸，先只显示原始墨迹，不打断书写。
② 双击写完一段，双击 Pencil Pro（或点工具栏「完成一段」）。
③ 选笔尖旁弹出「函数 / 求解 / 几何」；认出矩阵时多一枚「矩阵」。
④ 看笔迹淡出，换成标准式子、函数卡片、计算结果或标准图形。

使用场景

场景在纸上做什么用到的功能
学函数写下 f(x)，看图像、零点、极值点；拖滑条改系数，看图像怎么变。函数卡片
微积分作业验算写下积分、极限、求和，直接得到结果；对写过的函数求导、求定积分，卡片里画出导函数和面积。求解
平面和立体几何手画三角形、椭圆、正方体，变成标准图形；拖节点看边长、角度、面积怎么变；看三视图。几何
线性代数手写矩阵，算乘积、逆矩阵、行列式。矩阵
整理作业按题目分成多份草稿，下次打开回到上次的位置。多份草稿

02功能

本节截图来自 CI：在 iPad 模拟器上用 -demo 参数摆出的画面（main 分支 05a8037，2026-10-21），笔迹是预置的演示笔迹。画面里操作条上的引擎名和毫秒数是演示数据，不是实测值。

函数卡片 函数

  • 选「函数」：这段笔迹被识别成 LaTeX，手写淡出，换成标准式子。
  • 式子旁挂一张 GeoGebra 式的函数卡片：网格、坐标轴、零点和极值点；拖动平移、双指缩放、双击复位，Pencil 悬停读坐标；滑条可以改系数。
  • 点卡片标题栏选中后像 PS 的自由变换：拖四角 / 四边改大小，拖上方圆钮旋转（靠近整 90° 吸附），双指捏合缩放、转动；可以收起成一枚小胶囊。右上角的小眼睛只留图像和坐标轴。
  • 点式子出操作条：改式子（手动改 LaTeX）、改笔迹（原笔迹放回纸上，擦改后再双击更新这一条，卡片位置不变）、收起 / 展开图像、删除。拖动式子，卡片跟着走。

求解 求导 · 积分 · 极限 · 求和 · 解方程

写下要算的东西，双击选「求解」，App 直接算出结果并换成标准式子，算出来的部分是绿色的。引用的函数一改（改笔迹、改式子、拖滑条），下面的结果跟着重新算。怎么算：能用符号方法（代入、洛必达、原函数、求和公式）就给准确值；不行再用数值方法（双指数积分、Richardson 外推），并尽量认回 π/4、e − 1、√2、分数这样的形式，认不出就写 ≈ 六位有效数字。全部在 iPad 本机完成，不调用大模型。

类型手写的式子 → App 写回的结果（README 中的例子）
求导 在函数下面写 f ′(x)、f ″(x)、y ′、f ′(2)；也可以写 d/dx (x2 sin x)
积分 ∫ xex dx = xex − ex + C；∫10 x2 dx = 1/3；∫∞0 e−x dx = 1；∫20 f(x) dx = −16/3（卡片里涂出面积）
极限 limx→0 sin x / x = 1；limx→∞ (1 + 1/x)x = e；单侧 x → 0+；limx→3 f(x) 在卡片里标出那一点；左右极限不等、振荡时写明「极限不存在」
求和 / 连乘 ∑nk=1 k2 = n(n+1)(2n+1)/6；∑∞n=1 1/n2 = π2/6；∏5k=1 k = 120；发散时写明「级数发散」
方程 / 取值 x2 − 4 = 0 ⇒ x = ±2；对写过的函数取值 f(3)；不引用函数的完整算式直接算

几何 平面 · 立体 · 三视图 · 变立体

画一个图形，双击选「几何」，草图在本机被认成标准图形，画在纸上原来的位置。

能认的图形

  • 平面：线段、三角形（认出等边 / 等腰 / 直角，并把手抖修正成真的直角、真的等腰）、正方形、矩形、菱形、平行四边形、梯形、正多边形、圆、椭圆。接近水平的边会放平。
  • 立体：正方体 / 长方体、圆柱、圆锥、球、三棱柱、四棱锥、三棱锥。手画的虚线会连成一条。
  • 三角形加中线的草图沿用动态几何卡片（中点、重心跟着拖）。

能做的操作

  • 拖顶点改形状，图形保持性质（正方形拖角仍是正方形，平行四边形 / 菱形保持性质）；一般三角形随便拖，名字跟着变成「直角三角形」「等腰三角形」……
  • 拖上方圆钮旋转（整 15° 吸附）；圆拖边上的点改半径，椭圆拖半轴端点改 a、b 和方向。
  • 课本标注：顶点字母、直角记号、等边短线、ABCD-A1B1C1D1，看不见的棱画虚线。
  • 三视图；平面「变立体」：正方形 → 正方体、四棱锥，矩形 → 长方体，圆 → 圆柱、圆锥、球，三角形 → 三棱柱、三棱锥。

矩阵 计算 · 求逆矩阵 · 求行列式

  • 双击时先识别一遍：结果里有矩阵（pmatrix、bmatrix 等）时，菜单多一枚「矩阵」，点开是「计算 / 求逆矩阵 / 求行列式」。
  • 「计算」处理这一段里的一个或多个矩阵：加、减、乘、数乘、转置、已经写上的 ^{−1}；求逆、求行列式先把式子算成一个矩阵再做。
  • 元素只认常数，用精确分数运算（MathEngine 的有理数），结果写回成标准式子；不是方阵、没有逆时写在式子下面。
矩阵功能目前没有界面截图：CI 摆出的演示画面里没有矩阵这一幕。代码和单元测试在 Packages/InkCore（MatrixMath.swift、MatrixTests.swift）。

多份草稿 草稿画廊

  • 可以新建、搜索、排序；长按重命名、复制、删除。草稿里左上角回画廊，点名字改名。
  • 每份草稿自动存在 iPad 上：打开时每 3 秒有变化就存，离开、切到后台时也存。重新打开按 LaTeX 重建式子、导数和求解结果，并滚回上次的位置。
  • 纸可以上下滚，写到靠近底下自动接长；式子、卡片、图形跟着笔迹一起滚。台前调度、分屏等窗口化场景下，工具栏收成右上角一枚小胶囊。

04AI 实践和端云协同

AI 做什么：读懂手写

主识别（云端）：阿里云百炼 Qwen 视觉模型

  • 上传这一段笔迹的白底截图（PNG），模型只返回 {"latex": …}。
  • 先用 qwen3.8-flash（关闭思考），失败换 qwen3-vl-plus。
  • 设置里选「直连百炼」时排第一个；也可经 Mac 上的 Server 转调。

兜底（设备端）：MyScript iink 数学识别

  • 直接读笔画，收成 LaTeX，笔迹不上传。
  • 千问出错、结果为空或没网时接手。
  • iink 每次启动会联网到 license.myscript.com 查一次授权。

提示词只要求照抄。识别提示词要求「逐字照抄，不做任何数学判断；绝对不要改正、补全、化简或调整项的顺序」。2026-10-19 用手写风格字体（不是真人手写）测试写错的式子 3x2 − 3x：qwen3.8-flash、qwen3.8-max、qwen3-vl-plus 共 8 次，0 次被「改对」；单行耗时 flash 约 1.1–2 秒，max 约 1.7–2.9 秒。真人手写样本还没有系统地测。

AI 不做什么：计算

读懂之后的计算全部回到本机：Solver 用符号方法求准确值，不行再用数值积分和外推，并尽量认回 π、e、分数；矩阵用精确分数；几何草图用笔画规则识别拐点和形状。大模型只负责把手写变成 LaTeX，结果不依赖它的推理。

哪些在设备上、哪些在云端

环节位置说明
采集笔画设备PencilKit
决定何时识别、识别哪一段设备双击 Pencil 或点「完成一段」，只处理这一段
手写数学 → LaTeX云端为主，设备兜底百炼 Qwen（云端）→ MyScript（设备）→ Mac 上的 Server（转调 Qwen）
求导、积分、极限、求和、解方程、矩阵设备Solver、MatrixMath、MathEngine

函数图像、公式渲染设备SceneUI、SwiftMath
草稿保存设备存在 iPad 本机

怎么降级

  1. 千问优先（演示用）：设置里选「直连百炼」并填 Key：先用千问；出错或结果为空，换 MyScript（就绪时），再换 Server（填了地址时）。
  2. 其他选项：「自动」是 MyScript 先、再百炼、再 Server；也可以只指定 MyScript、Server 或回放。指定的引擎没配好时按自动的顺序来，不直接退到回放。
  3. 回放：三个引擎都没配置，或在设置里选「回放（断网）」时，按录好的 LaTeX 出结果（按「第几条、改过几轮、这一轮写了几笔」取）。彩排时打开「录制回放」，可以把真识别的结果录下来。Server 端默认在 3 秒没返回或出错时也放它录好的结果。
  4. 认错了：点式子「改式子」手动改 LaTeX，或「改笔迹」重写后再双击。链上的引擎都失败时，界面提示「没认出来」，App 不会自动切到回放。
「不联网也能用」指的是识别之后的计算、作图和保存。MyScript 每次启动要联网查一次授权，没网时 iink 会怎样还没实测；断网时千问用不了，识别链会退到 MyScript；但 MyScript 没网时的表现还没实测，所以会场断网最稳的做法是在设置里切到「回放」。

已知限制

  • 矩阵元素只认常数。
  • MathEngine 的多项式部分只支持单变量多项式。Solver 算不了的式子写明原因（例如「暂时算不出来」），认不出准确形式时写 ≈ 小数，不硬给答案。
  • MyScript 证书、数学识别资源和百炼 Key 都不进仓库，换一台设备要重新配置。
