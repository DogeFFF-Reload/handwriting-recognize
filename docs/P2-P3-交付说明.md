## 1. 三个分支

| 分支 | 内容 | 云端验证 |
| --- | --- | --- |
| `p3/ink` | `Packages/InkCore`：按 y 带状分行、批改门禁、按笔画切项、几何草图识别、契约 Codable、识别器、说明模板、求导批改（临时）；`Server/`：Vapor 服务 | Linux 上 `swift test` 全过；整个 App 用 Xcode 16.4 编成 iOS 模拟器版 `BUILD SUCCEEDED` |
| `p2/scene` | `Packages/SceneUI`：函数图像、系数滑条、极值点和水平切线、导函数虚线、可拖切点（A9）、GeoGebra 式动态几何、SwiftMath 公式组件 | 整个 App `BUILD SUCCEEDED` |
| `demo/integration` | 上面两个合在一起，外加把它们接进 App 的 4 个文件（`AppModel`、`PencilCanvas`、`InkOverlay`、`ContentView`） | 见 Actions |

**P1 怎么用**：`demo/integration` 是可选的。直接合进 `main` 就能装机试前两幕；也可以只拿 `Packages/` 下的两个包，App 里的接法照 `app/InkTutor/AppModel.swift` 抄。App 里的四个文件是 P1 的地盘，改不改由 P1 定。

没有在真机上跑过。Pencil 双击、捏压、PencilKit 整笔擦除、真人手写的识别准确率，都要在那台 iPad Pro 上看。

## 2. 接口（都在 `InkCore`，不改 P1 定的 `InkLine` / `InkModeling` / `CheckGating`）

- `BandInkModel: InkModeling`：每次传入画布上**全部**笔画，自己比对出新增和删除。中心落在行带（上下外扩 0.3 倍行高）里就归入该行，否则建新行 `L<n>`。行号不复用。几何模式全部进 `G1`。每次增删 `revision + 1`，被删的笔画进 `removedStrokeIDs`，上传后调用 `markSent(lineID:)`。
- `CheckGate: CheckGating`：停 700 ms 调 `onRecognize(line, .pause)`；能解析、项数够、1.5 s 无新笔画时调 `onCheck(line, .autoCheck)`；双击跳过等待和项数；解析失败时调 `onUnreadable`。函数模式不批改，双击等于立即识别。同一版本只自动批一次，过期的识别结果直接丢弃。计时器可以注入，单测用的是假时钟。
- `PencilKitBridge`：`PKDrawing` 转成 `[InkStroke]`（id 用 creationDate 加外框；iPadOS 27 起可以换成 `PKStroke` 自带的 UUID），并取某一行的白底 PNG。
- `InkRecognizer` 协议的四个实现：
  - `DashScopeRecognizer`：直连百炼，`qwen3.8-flash`，失败换 `qwen3-vl-plus`；
  - `ServerRecognizer`：经 Mac 上的 Server；
  - `ReplayRecognizer`：回放；
  - `AppleStrokeRecognizer`：iPadOS 27 的 `PKStrokeRecognizer`。默认不编译，要 Xcode 27，在编译条件里加 `PKSTROKERECOGNIZER` 才打开。它面向文字，官方没说支持上标，只当候选引擎实测。
- `LatexTerms.parse`：识别结果解析成「函数 / 导数行 + 按书写顺序的项」，门禁用它判断能不能解析、写了几项。
- `TermSegmenter.termBoxes`：用笔画外框按等号、加减号切项，给圈错项用。项数和识别结果对不上时返回 nil，调用方退回圈整行。这是 A4 的不依赖 MyScript 版本。
- `DerivativeCheck`：第二幕的逐项比对，生成 `Annotation`。direct 模式带 `expected_latex` 和模板说明，例如「x 求导得 1，所以 −3x 求导后是 −3。」；socratic 模式不带。**这是 P4 的 MathEngine 到之前的临时实现**，MathEngine 到了就换掉，批注形状不变。
- `GeometrySketchRecognizer`（A5）：笔画先简化成折线，从中找出三角形，再认中线（一端靠近顶点、另一端落在对边中点 15% 边长范围内）。输出和 `contracts/scene-geometry.sample.json` 同形。认不出返回 nil，不硬收。
- `Explanation`：按错误码生成一句说明，不调模型。

## 3. 识别实测（2026-10-19，用的是手写风格字体，不是真人手写）

`qwen3.8-flash`、`qwen3.8-max`、`qwen3-vl-plus` 用 `recognitionPrompt` 识别写错的式子 `3x^2-3x`，8 次里 0 次被「改对」。单行耗时：flash 约 1.1–2 秒，max 约 1.7–2.9 秒。账号里**没有** `qwen3.8-plus` 和 `qwen3-vl-flash`。北京区的 Key 就能用，不用另申新加坡区。Qwen 返回的坐标是 0–1000 归一化值，不是像素（A7）。

真人手写还要用 S01–S20 测一遍。

## 4. iPad 上怎么试（demo/integration）

1. 齿轮 › 识别引擎选「直连百炼」，填 Key。Key 只存在这台 iPad 的 UserDefaults 里，不进仓库。没有 Key 时会按顺序回放黄金路径的四行。
2. 模式选「函数」，写 `f(x)=x^3-5x`。停笔后笔迹下方出现回显，右半屏出曲线和 a、b 两个滑条。点「笔/橡皮」（或捏一下 Pencil Pro）擦掉 5，写 3，图像随之变化。
3. 模式切到「推导」，写 `f'(x)=3x^2-3x`。写满 2 项、停 1.5 秒后自动批改（也可以双击 Pencil），圈出 `-3x`，旁边写着「应为 −3」和一句说明。擦掉改成 `-3` 后出现绿勾，右半屏标出极值点 (−1, 2)、(1, −2)、水平切线、导函数虚线，以及一个可拖的切点。
4. 模式切到「几何」，画三角形和中线，双击确认，右半屏变成可拖的动态几何。
5. 回显认错了，点一下回显手动改，推导行会立即重批。

走 Server（`cd Server && swift run InkTutorServer`，端口 8080）需要 App 能访问局域网 http，要在 Info.plist 里加 `NSAllowsLocalNetworking` 和 `NSLocalNetworkUsageDescription`。初赛建议先用直连百炼。

## 5. CI

`.github/workflows/ci.yml`：push 到 `p2/**`、`p3/**`、`p4/**`、`demo/**` 时，在 Linux 上跑 InkCore 和 Server 的单测。commit 信息带 `[mac]` 时，再用 macOS 把整个 App 编一遍。macOS 分钟按 10 倍计费，算在仓库主人的额度里，别每次都带。
